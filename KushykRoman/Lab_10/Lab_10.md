## Завдання 1. Використання декоратора `@property` (створення Getter'а)

Часто в класі є властивості, які залежать від інших властивостей. Наприклад, електронна пошта працівника може генеруватися з його імені та прізвища. Якщо ми змінимо ім'я, пошта має оновитися автоматично. 
Декоратор `@property` перетворює звичайний метод класу на "розумну змінну" (getter). Ми звертаємося до нього без дужок (як до звичайної властивості), але всередині кожного разу виконується код, який повертає свіжий результат.

```python
class Employee:
    def __init__(self, first_name, last_name):
        self.first_name = first_name
        self.last_name = last_name

    @property
    def email(self):
        return f"{self.first_name.lower()}.{self.last_name.lower()}@company.com"

emp = Employee("Іван", "Франко")

print(f"Початкова пошта: {emp.email}")

emp.first_name = "Петро"

print(f"Оновлена пошта: {emp.email}")
```


## Завдання 2. Концепція Getter’ів, Setter’ів і Deleter’ів


Як ми хочемо не лише отримувати динамічне значення (Getter), але й задавати його напряму (Setter)? Наприклад, ми хочемо написати `emp.fullname = "Тарас Шевченко"`, і щоб програма сама зрозуміла, що "Тарас" — це `first_name`, а "Шевченко" — це `last_name`.
Для цього після створення `@property` ми використовуємо декоратори `@назва_властивості.setter` (для зміни) та `@назва_властивості.deleter` (для видалення). Також Setter'и ідеально підходять для перевірки даних (наприклад, щоб не дозволити встановити від'ємну зарплату).

```python
class Employee:
    def __init__(self, first_name, last_name):
        self.first_name = first_name
        self.last_name = last_name

    @property
    def fullname(self):
        return f"{self.first_name} {self.last_name}"

    @fullname.setter
    def fullname(self, name):
        first, last = name.split(" ")
        self.first_name = first
        self.last_name = last
        print(f"Повне ім'я успішно змінено на: {name}")

    @fullname.deleter
    def fullname(self):
        print("Увага: Очищення імені та прізвища!")
        self.first_name = None
        self.last_name = None

emp = Employee("Леся", "Українка")
print(f"Створено працівника: {emp.fullname}")

emp.fullname = "Ліна Костенко"
print(f"Нове ім'я в системі: {emp.first_name}") # Виведе "Ліна"
print(f"Нове прізвище в системі: {emp.last_name}") # Виведе "Костенко"

del emp.fullname
print(f"Ім'я після видалення: {emp.first_name}") # Виведе None
```


## Відповіді на запитання для самоконтролю

**1. Що таке “декоратор методу”?**
Декоратор методу — це спеціальна функція в Python, яка дозволяє змінити або розширити поведінку іншого методу, не змінюючи при цьому його базовий вихідний код. У коді декоратори позначаються символом `@` перед назвою (наприклад, `@property`) і розміщуються безпосередньо над методом, який вони "декорують".

**2. Які декоратори Вам відомі?**
Завдяки цій та попереднім лабораторним роботам, тобі тепер відомі такі вбудовані декоратори в ООП:
*   `@classmethod` — перетворює звичайний метод на метод класу (приймає `cls` замість `self`).
*   `@staticmethod` — створює статичний метод, який не прив'язаний ні до об'єкта, ні до класу.
*   `@property` — перетворює метод на властивість (getter), дозволяючи звертатися до нього без дужок.
*   `@назва.setter` — дозволяє призначати значення для властивості, створеної через `@property`.
*   `@назва.deleter` — визначає логіку при спробі видалити властивість за допомогою оператора `del`.

**3. Для чого використовуються getter’и і setter’и? В чому їх перевага над іншими способами доступу до властивостей об’єктів?**
Вони використовуються для контролю доступу до внутрішніх даних об'єкта (інкапсуляції). 
**Головна перевага:** безпека та гнучкість. Якщо ми дозволимо змінювати змінні напряму (наприклад, `emp.salary = -500`), хтось може ввести некоректні дані і зламати програму. Setter дозволяє перехопити це присвоєння і додати перевірку (наприклад, `if new_salary < 0: raise ValueError`). При цьому для зовнішнього користувача синтаксис залишається простим і зручним (`об'єкт.властивість = значення`), без необхідності викликати складні функції на кшталт `emp.set_salary(500)`.
