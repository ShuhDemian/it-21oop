## Завдання 1. Створення атрибутів, один з яких базується на інших

Коли ми ініціалізуємо об'єкт у методі `__init__`, ми можемо не лише зберігати передані аргументи, але й виконувати з ними математичні або логічні операції, щоб одразу створити новий (похідний) атрибут.

```python
class Employee:
    def __init__(self, name, base_salary, bonus):
        self.name = name                 
        self.base_salary = base_salary   
        self.bonus = bonus               
        
        
        self.total_salary = self.base_salary + self.bonus


emp = Employee("Олексій", 20000, 5000)
print(f"Повна зарплата працівника {emp.name}: {emp.total_salary} грн.")
```

## Завдання 2. Метод генерування опису об’єкта

Метод, який описує об'єкт, просто збирає значення його атрибутів (через `self`) і форматує їх у зручний для читання рядок.

```python
class Employee:
    def __init__(self, name, position):
        self.name = name
        self.position = position

    def get_description(self):
        return f"Працівник: {self.name}, Посада: {self.position}."

emp = Employee("Марія", "Дизайнер")
print(emp.get_description())
```
## Завдання 3. Виклик методу через об'єкт та через клас

Зазвичай ми викликаємо методи через створений об'єкт: `обєкт.метод()`. При цьому Python автоматично передає цей об'єкт як прихований аргумент `self`. 
Але можна викликати метод і безпосередньо через сам клас: `Клас.метод(обєкт)`. У цьому випадку ми маємо **вручну** передати об'єкт у дужки, щоб метод зрозумів, з чиїми даними йому працювати (тобто явно передати `self`).

```python
class Employee:
    def __init__(self, name):
        self.name = name

    def say_hello(self):
        print(f"Привіт! Мене звати {self.name}.")

emp1 = Employee("Іван")
emp2 = Employee("Анна")

emp1.say_hello()

Employee.say_hello(emp2)
```


## Завдання 4. Змінна класу та метод, що її використовує

Змінна класу оголошується безпосередньо в тілі класу (поза методом `__init__`). Вона однакова для всіх об'єктів цього класу. До неї можна звертатися через ім'я класу (наприклад, `Employee.company_name`).

```python
class Employee:
    company_name = "Global Tech" 

    def __init__(self, name):
        self.name = name

    def get_company_info(self):
        print(f"{self.name} працює в компанії {Employee.company_name}.")

emp1 = Employee("Олег")
emp2 = Employee("Ірина")

emp1.get_company_info()
emp2.get_company_info()
```


## Завдання 5. Лічильник створених об’єктів

Щоб рахувати кількість створених об'єктів, нам ідеально підходить змінна класу. Ми задаємо їй початкове значення `0`, а потім всередині методу `__init__` (який спрацьовує при кожному створенні об'єкта) збільшуємо її на одиницю.

```python
class Employee:
    total_employees = 0 

    def __init__(self, name):
        self.name = name
        Employee.total_employees += 1

print(f"Працівників до: {Employee.total_employees}")

emp1 = Employee("Тарас")
emp2 = Employee("Олена")
emp3 = Employee("Максим")

print(f"Працівників після: {Employee.total_employees}")
```


## Запитання для самоконтролю

**1. Як створити порожній клас?**
Для цього використовується ключове слово `class`, назва класу, двокрапка, а в тілі класу пишеться ключове слово `pass`, яке означає "нічого не робити".
```python
class MyEmptyClass:
    pass
```

**2. Який метод призначений для створення нового об’єкта?**
Безпосередньо за виділення пам'яті та створення об'єкта відповідає магічний метод `__new__`. Але на практиці програмісти найчастіше працюють з методом **`__init__`** (конструктором/ініціалізатором), який автоматично викликається відразу після `__new__` і призначений для наповнення цього нового об'єкта початковими властивостями (змінними).

**3. Що виведеться у консоль, якщо виконати команду `print(obj.method)` (метод без дужок)?**
Оскільки дужок немає, метод **не виконається**. У консоль виведеться технічна інформація про те, що це за об'єкт в пам'яті. Це буде виглядати приблизно так: `<bound method ClassName.method of <__main__.ClassName object at 0x7f8b...>>`. Це означає: "це прив'язаний метод такого-то об'єкта за такою-то адресою в пам'яті". Щоб метод спрацював і повернув результат, обов'язково потрібні дужки: `print(obj.method())`.

**4. Яка різниця між змінною об’єкта і класу?**
*   **Змінна класу** створюється всередині класу, але поза його методами. Вона є **спільною** для всіх екземплярів (об'єктів) цього класу. Якщо змінити змінну класу, вона зміниться для всіх.
*   **Змінна об'єкта** створюється всередині методу `__init__` з використанням слова `self` (наприклад, `self.name = "Іван"`). Вона належить **тільки конкретному об'єкту**. У кожного об'єкта ця змінна має своє власне, незалежне значення.
