## Завдання 1 та 2. Поняття поліморфізму та перевизначення поведінки методів

Перевизначення (Method Overriding) — це один із найпоширеніших проявів поліморфізму. Воно відбувається, коли дочірній клас створює метод з **такою самою назвою**, як і в батьківському класі, але пише для нього **свою власну логіку**. 
Завдяки цьому ми можемо звертатися до різних об'єктів однаково, а кожен з них буде реагувати по-своєму.

```python
# Батьківський клас
class Employee:
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

    # Базовий метод розрахунку премії
    def calculate_bonus(self):
        return self.salary * 0.10 

# Дочірній клас 1
class Developer(Employee):
    def calculate_bonus(self):
        return self.salary * 0.20 

# Дочірній клас 2
class Manager(Employee):
    def calculate_bonus(self):
        return self.salary * 0.15 
        
emp = Employee("Іван", 10000)
dev = Developer("Олена", 10000)
mgr = Manager("Петро", 10000)

# ПОЛІМОРФІЗМ У ДІЇ:
print(f"Премія звичайного працівника: {emp.calculate_bonus()} грн")
print(f"Премія розробника: {dev.calculate_bonus()} грн")
print(f"Премія менеджера: {mgr.calculate_bonus()} грн")
```


## Завдання 3. Реалізація "магічних методів" (Dunder methods)

"Магічні методи" (або dunder методи, від *double underscore*) — це спеціальні методи в Python, які починаються і закінчуються двома підкресленнями (наприклад, вже знайомий нам `__init__`). Вони дозволяють нашим власним об'єктам взаємодіяти з вбудованими операторами Python (такими як `+`, `-`, `==`, або функціями `print()`, `len()`). 
Це також форма поліморфізму — ми "навчаємо" стандартні оператори працювати з нашими новими типами даних!

```python
class Employee:
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

    # Магічний метод __str__ 
    def __str__(self):
        return f"[Працівник: {self.name} | Зарплата: {self.salary} грн]"

    # Магічний метод __add__
    def __add__(self, other_employee):
        # Наприклад, при додаванні двох працівників ми хочемо отримати суму їхніх зарплат
        return self.salary + other_employee.salary

    # Магічний метод __eq__ (від "equal")
    def __eq__(self, other_employee):
        return self.salary == other_employee.salary

# Створюю об'єкти
emp1 = Employee("Андрій", 25000)
emp2 = Employee("Світлана", 30000)
emp3 = Employee("Олег", 25000)

# 1. Перевірка __str__
print(emp1)  # Замість незрозумілої адреси в пам'яті виведеться гарний текст

# 2. Перевірка __add__ (додаємо об'єкти!)
total_budget = emp1 + emp2
print(f"Спільний бюджет на зарплату двох працівників: {total_budget} грн")

# 3. Перевірка __eq__
print(f"Чи однакова зарплата у Андрія та Світлани? - {emp1 == emp2}")
print(f"Чи однакова зарплата у Андрія та Олега? - {emp1 == emp3}")
```


## Відповіді на запитання для самоконтролю

**1. Поясніть концепцію поліморфізму.**
Поліморфізм — це принцип ООП, який дозволяє сутностям з різною внутрішньою структурою (різним класам) мати однаковий зовнішній інтерфейс (назви методів). Завдяки цьому програма може працювати з об'єктами різних класів єдиним універсальним способом, не знаючи заздалегідь, до якого саме класу належить об'єкт. Python сам "під капотом" розбереться, яку саме версію методу викликати.

**2. Наведіть приклад застосування поліморфізму.**
Класичний приклад: у нас є класи `Dog`, `Cat` та `Cow`, і всі вони мають метод `make_sound()`. Ми можемо створити список тварин: `animals = [Dog(), Cat(), Cow()]`, а потім пройтися по ньому циклом, викликаючи `animal.make_sound()`. Кожна тварина видасть свій унікальний звук (гавкіт, нявкання, мукання), хоча ми викликали абсолютно ідентичний метод для всіх. В нашому коді вище ми так само по-різному рахували премію (`calculate_bonus()`) для різних посад.

**3. Що таке “магічні методи”? Які з них Вам відомі?**
Магічні методи — це спеціальні методи класів у Python, імена яких починаються і закінчуються двома символами підкреслення (dunder methods). Вони не викликаються напряму розробником (через крапку), а спрацьовують автоматично під час використання стандартних синтаксичних конструкцій та операторів мови.
*Відомі методи:*
*   `__init__` (ініціалізація об'єкта)
*   `__str__` (рядкове представлення об'єкта, зручне для людини, викликається функцією `print()`)
*   `__repr__` (офіційне рядкове представлення для розробників)
*   `__add__` (визначає поведінку для оператора `+`)
*   `__eq__` (визначає поведінку для оператора порівняння `==`)
*   `__len__` (визначає поведінку для функції `len()`)
