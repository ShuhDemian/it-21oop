## Завдання 1 та 2. Створення батьківського і дочірніх класів, використання `super()`

**Батьківський клас (суперклас)** містить загальні властивості, які притаманні всім. **Дочірній клас (підклас)** переймає ці властивості, але може додавати свої унікальні або змінювати існуючі. 
Щоб не писати наново код ініціалізації (`__init__`) для тих властивостей, які вже описані в батьківському класі, дочірній клас використовує функцію `super()`. Вона каже: "Сходи в батьківський клас і виконай його метод, а потім я додам своє".

```python
# БАТЬКІВСЬКИЙ КЛАС
class Employee:
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

    def work(self):
        print(f"{self.name} виконує загальну роботу.")

# ДОЧІРНІЙ КЛАС 1
class Developer(Employee):
    def __init__(self, name, salary, programming_language):
        super().__init__(name, salary)
        self.programming_language = programming_language

    def work(self):
        print(f"Розробник {self.name} пише код на {self.programming_language}.")

# ДОЧІРНІЙ КЛАС 2
class Manager(Employee):
    def __init__(self, name, salary, department):
        super().__init__(name, salary)
        self.department = department

    def work(self):
        print(f"Менеджер {self.name} керує відділом {self.department}.")

dev = Developer("Олександр", 40000, "Python")
mgr = Manager("Анна", 50000, "IT")

dev.work() 
mgr.work() 
print(f"Зарплата розробника: {dev.salary}")
```

## Завдання 3. Використання методів іншого дочірнього класу

Об'єкти різних дочірніх класів можуть чудово взаємодіяти між собою. Наприклад, ми можемо передати об'єкт розробника (`Developer`) всередину методу менеджера (`Manager`), щоб менеджер змусив розробника працювати. Це називається композицією/агрегацією — коли один об'єкт використовує інший.

```python
# Використовую класи з попереднього прикладу

class Manager(Employee):
    def __init__(self, name, salary, department):
        super().__init__(name, salary)
        self.department = department

    def assign_task(self, developer_obj, task):
        print(f"Менеджер {self.name} дає завдання '{task}' розробнику {developer_obj.name}.")
        developer_obj.work()

dev = Developer("Ігор", 45000, "Java")
mgr = Manager("Олена", 60000, "Розробка")

mgr.assign_task(dev, "Створити базу даних")
```

## Завдання 4. Ознайомлення з методами `isinstance()` та `issubclass()`


*   `isinstance(об'єкт, Клас)` — перевіряє, чи є конкретний об'єкт екземпляром вказаного класу (або його дочірнього класу). Повертає `True` або `False`.
*   `issubclass(Клас1, Клас2)` — перевіряє, чи є Клас1 дочірнім по відношенню до Класу2. Працює з самими класами, а не з об'єктами.

```python
dev = Developer("Максим", 30000, "C++")

print("Чи є dev об'єктом класу Developer?", isinstance(dev, Developer)) 
print("Чи є dev об'єктом класу Employee?", isinstance(dev, Employee))  
print("Чи є dev об'єктом класу Manager?", isinstance(dev, Manager))

print("Чи є Developer дочірнім від Employee?", issubclass(Developer, Employee)) 
print("Чи є Employee дочірнім від Manager?", issubclass(Employee, Manager))     
```


## Відповіді на запитання для самоконтролю

**1. Дайте визначення поняттю “наслідування” в об’єктно-орієнтованому програмуванні.**
Наслідування — це механізм ООП, який дозволяє створити новий клас на основі вже існуючого. Новий клас автоматично отримує (успадковує) всі змінні та методи старого класу, і при цьому може додавати свої власні або змінювати успадковані.

**2. Для чого використовується наслідування?**
Головна мета — **повторне використання коду** (принцип DRY - Don't Repeat Yourself). Замість того, щоб копіювати однаковий код (наприклад, ім'я та зарплату) в класи розробника, тестувальника і менеджера, ми виносимо це в один загальний клас працівника. Це робить програму меншою, логічнішою і легшою для оновлення.

**3. Що таке “батьківський” і “дочірній” класи?**
*   **Батьківський (базовий, суперклас):** існуючий клас, чиї властивості та методи передаються іншим. (Наприклад: `ТранспортнийЗасіб`).
*   **Дочірній (похідний, підклас):** новий клас, який створюється на основі батьківського. Він успадковує його функціонал і розширює його. (Наприклад: `Автомобіль`, `Велосипед`).

**4. Опишіть функціонал методу `super()`.**
Функція `super()` у дочірньому класі повертає тимчасовий об'єкт батьківського класу. Вона використовується для того, щоб викликати методи батьківського класу (найчастіше `__init__`). Це дозволяє спочатку виконати логіку предка (наприклад, записати загальні дані), а потім продовжити виконання специфічної логіки нащадка.

**5. Як звернутися до класу, що має спільного із поточним класом предка?**
Такі класи називаються "сестринськими" (siblings). У Python немає спеціального ключового слова (як-от `super()`), щоб автоматично звернутися до сестринського класу. Вони незалежні один від одного. Щоб вони взаємодіяли, ми зазвичай передаємо екземпляр одного дочірнього класу як аргумент у метод іншого дочірнього класу (як ми це зробили в Завданні 3, передавши `Developer` у метод класу `Manager`).
