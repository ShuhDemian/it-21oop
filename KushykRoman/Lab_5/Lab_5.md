## Завдання 1. Оголошення класів в Python 3

Клас оголошується за допомогою ключового слова `class`, після якого йде назва класу та двокрапка. Загальноприйнято писати назви класів з великої літери (стиль CamelCase). Усе, що написано з відступом під цим оголошенням, належить до цього класу. Якщо клас поки що нічого не робить, ми використовуємо ключове слово `pass`, щоб уникнути помилки синтаксису.

```python
class Student:
    pass

print("Клас Student успішно оголошено!")
```


## Завдання 2. Створення об’єктів

Щоб створити об'єкт (екземпляр), потрібно написати назву класу і додати круглі дужки, ніби ти викликаєш функцію. Цей процес називається інстанціюванням (instantiation). Створений об'єкт зазвичай зберігають у змінну, щоб потім з ним працювати.

```python
class Student:
    pass

student_1 = Student()
student_2 = Student()

print(f"Об'єкт 1 створено. Його тип: {type(student_1)}")
print(f"Об'єкт 2 створено. {student_1 != student_2}")
```

## Завдання 3. Змінні (властивості) обʼєкту

Властивості — це дані, які зберігаються всередині конкретного об'єкта. Правильний спосіб задати їх при створенні — використати спеціальний метод ініціалізації `__init__`. Першим параметром цього методу завжди є `self` (посилання на сам об'єкт, який зараз створюється). Щоб отримати або змінити значення властивості вже створеного об'єкта, використовується "крапкова нотація" (`ім_я_обєкта.назва_властивості`).

```python
class Student:
    def __init__(self, name, age):
        self.name = name  
        self.age = age    

my_student = Student("Олена", 20)

print(f"Ім'я студента: {my_student.name}, Вік: {my_student.age}")

my_student.age = 21
print(f"Оновлений вік: {my_student.age}")
```


## Завдання 4. Функції об’єкту (методи)

Функції, які належать класу, називаються методами. Вони описують те, що об'єкт вміє робити (його поведінку). Як і `__init__`, кожен метод об'єкта повинен приймати `self` як перший параметр. Це дозволяє методу мати доступ до змінних цього ж об'єкта. Викликаються методи також через крапку.

```python
class Student:
    def __init__(self, name):
        self.name = name
        
    def study(self, subject):
        print(f"Студент {self.name} зараз вивчає предмет: {subject}.")


my_student = Student("Іван")

my_student.study("Програмування на Python")
```

## Завдання 5. Комплексний приклад (розв'язання задачі)

Для закріплення об'єднаємо все в одну повноцінну міні-програму. Уявимо, що нам треба змоделювати банківський рахунок, де ми використовуємо клас, створюємо об'єкт, маємо змінну балансу та методи для поповнення і зняття коштів.

```python
class BankAccount:
    def __init__(self, owner, initial_balance=0):
        self.owner = owner
        self.balance = initial_balance

    def deposit(self, amount):
        self.balance += amount
        print(f"Рахунок поповнено на {amount} грн. Поточний баланс: {self.balance} грн.")

    def withdraw(self, amount):
        if amount > self.balance:
            print("Помилка: Недостатньо коштів на рахунку!")
        else:
            self.balance -= amount
            print(f"Знято {amount} грн. Поточний баланс: {self.balance} грн.")

my_account = BankAccount("Тарас Шевченко", 1000)

print(f"Власник рахунку: {my_account.owner}")
my_account.deposit(500)
my_account.withdraw(200)
my_account.withdraw(5000)
```
## Відповіді на запитання для самоконтролю
**1. Дайте визначення поняттю “клас”. Як оголосити найпростіший клас в Python 3?**
Клас — це користувацький тип даних, своєрідний шаблон, креслення або схема, яка визначає набір властивостей (змінних) та методів (функцій), що будуть спільними для всіх об'єктів цього типу.
Найпростіший клас у Python 3 оголошується за допомогою ключового слова class:

Python
class MyFirstClass:
    pass # Ключове слово pass означає, що клас поки що порожній
**2. Що таке об’єкт? Як створюється об’єкт?**
Об’єкт (або екземпляр класу) — це конкретна сутність, створена за шаблоном певного класу, яка містить власні реальні дані. Об'єкт створюється шляхом виклику імені класу так, ніби це функція (з дужками), куди за потреби передаються початкові параметри:

Python
my_object = MyFirstClass()
**3. В чому полягає різниця між класом і об’єктом?**
Клас — це абстракція, опис того, якими характеристиками та поведінкою повинні володіти сутності. Об'єкт — це вже конкретна реалізація цього опису в оперативній пам'яті програми. З одного класу можна створити безліч різних об'єктів з різними даними.

**4. Що таке змінна обʼєкту?**
Змінна об’єкту (або атрибут об'єкту) — це характеристика або властивість, яка належить конкретному екземпляру класу. Наприклад, у класу Dog змінною об'єкту може бути self.name або self.age. Кожен об'єкт (кожен конкретний собака) матиме своє власне ім'я та вік.

**5. Як викликати функцію класу?**
Функція, що належить об'єкту, називається методом. Вона викликається через ім'я конкретного об'єкта, після якого ставиться крапка, ім'я методу і дужки:

Python
object_name.method_name()
**6. Як імпортувати клас з зовнішнього файлу?**
Якщо ваш клас збережено в іншому файлі (модулі), наприклад, у файлі з назвою models.py, ви можете імпортувати його у свій основний скрипт за допомогою ключових слів from та import:

Python
from models import MyFirstClass
**7. Яку відповідність з реального світу Ви могли б навести для понять класу та об'єкта?**

Найкраща аналогія — це будівництво.

Клас — це архітектурне креслення будинку. На ньому вказано, де будуть стіни, скільки буде вікон і дверей. Але жити в кресленні неможливо.

Об'єкт — це реальний будинок, збудований за цим кресленням на конкретній вулиці. За одним кресленням (класом) можна збудувати ціле котеджне містечко (безліч об'єктів), і кожен будинок може мати різний колір стін чи меблі всередині (змінні об'єкта).

Інша популярна аналогія: формочка для печива (клас) та саме випечене печиво (об'єкти).
