## Відповіді на питання для самоконтролю

1. Як встановити та запустити?
Спочатку треба завантажити Python з офіційного сайту python.org. При встановленні обов'язково поставити галочку "Add Python to PATH". Як середовище (IDE) найзручніше поставити VS Code або PyCharm.
Запустити програму можна двома способами:

* Натиснути кнопку "Run" (зелений трикутник) у середовищі розробки.
* Відкрити термінал і написати: `python nazva_faily.py`.

2. Відмінності Windows та Unix (Linux/macOS):
Основна різниця — це файлові шляхи. У Windows використовуються обернені слеші (`\`), а в Unix — звичайні (`/`).
Також у терміналі Linux/macOS часто треба писати команду `python3`, щоб викликати саме третю версію, а у Windows зазвичай вистачає просто `python`.

3. Структура програми:
У Python структура максимально проста. На відміну від C++, тут не обов'язково оголошувати функцію `main` чи підключати купу бібліотек для простого виводу тексту. Програма виконується рядок за рядком зверху вниз.
*Приклад:*
`print("Hello World")` — це вже повноцінна програма.

4. Ввід-вивід та операції:

* Ввід: функція `input()` (вона зчитує рядок, тому для чисел треба перетворювати через `int()` або `float()`).
* Вивід: функція `print()`.

Часто використовуються арифметичні оператори:

* `+`, `-`, `*`, `/` (стандартні).
* `//` — цілочисельне ділення (відкидає дробову частину).
* `%` — остача від ділення.
* `**` — піднесення до степеня.

5. Команди Git:
Найбільш вживані:

* `git init` — створити репозиторій у папці.
* `git clone [url]` — скачати проект з інтернету.
* `git add .` — додати всі змінені файли до індексу.
* `git commit -m "коментар"` — зберегти зміни.
* `git push` — відправити зміни на сервер (GitHub).
* `git status` — подивитися, які файли змінено.
