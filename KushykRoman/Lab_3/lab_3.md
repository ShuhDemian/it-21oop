Суть структурного програмування Структурне програмування — це підхід, при якому будь-яка програма будується з трьох базових керуючих структур: • Слідування: інструкції виконуються послідовно, одна за одною. • Розгалуження (умови): виконання певного блоку коду залежить від істинності умови. • Цикл: багаторазове повторення блоку коду. У Python структурність підтримується на рівні синтаксису: замість фігурних дужок {} для виділення блоків коду використовуються відступи (зазвичай 4 пробіли). Це автоматично робить код читабельним і структурованим.
Використання умовних операторів У Python для розгалужень використовується конструкція if, elif (скорочення від else if) та else. Дужки навколо умови ставити не обов'язково, а після умови обов'язково ставиться двокрапка :.

Оператори булевої логіки в Python 3 На відміну від багатьох інших мов, де використовуються символи &&, || та !, у Python булеві оператори пишуться словами, що робить код схожим на звичайну англійську мову: • and (логічне І): істинно, якщо обидві умови істинні. • or (логічне АБО): істинно, якщо хоча б одна умова істинна. • not (логічне НІ): змінює значення на протилежне.
Проектування складних умов Складні умови створюються шляхом комбінування простих за допомогою булевих операторів. Для визначення пріоритету операцій можна використовувати круглі дужки. Приклад перевірки того, чи входить число в певний діапазон і чи є воно парним:

number = 16
if (number >= 10 and number <= 20) and not (number % 2 != 0):
    print("Число парне і знаходиться в діапазоні від 10 до 20")
    
if 10 <= number <= 20 and number % 2 == 0:
    print("Цей запис працює так само, але він значно елегантніший")

Методи роботи з циклами та їх доцільність У Python є два основних типи циклів: while та for. • Цикл while (цикл із передумовою): Використовується тоді, коли кількість ітерацій заздалегідь невідома, і цикл має продовжуватися, поки виконується певна умова.

k = 1
while 2**k <= 100:
    k += 1
print("Шуканий степінь:", k)
Шуканий степінь: 7

• Цикл for (цикл ітерації): Використовується тоді, коли відома точна кількість повторень або коли потрібно пройтися по елементах колекції (списку, рядку тощо). Найчастіше використовується з функцією range().


number = 1
for i in range(1, 6): 
    if i % 2 != 0:   
        number*= i
print("Добуток непарних чисел від 1 до 5:", number)
Добуток непарних чисел від 1 до 5: 15

Для керування циклами також використовуються оператори break (дострокове завершення циклу) та continue (перехід до наступної ітерації).

Дайте визначення поняттю “структурне програмування”.
Структурне програмування — це методологія розробки програмного забезпечення, яка базується на представленні програми у вигляді ієрархічної структури блоків. Головна ідея полягає у відмові від хаотичних переходів (таких як goto) на користь трьох базових керуючих конструкцій: • Слідування (Sequence): послідовне виконання команд одна за одною. • Розгалуження (Selection): вибір шляху виконання залежно від умови (if, else). • Повторення (Iteration): багаторазове виконання блоку коду (цикли). Цей підхід робить код більш читабельним, логічним і легшим для налагодження.

Який синтаксис умовних операторів у Python 3? У Python синтаксис умовних операторів базується на ключових словах if, elif та else. Особливістю є використання відступів (indentation) для виділення блоків коду та двокрапки (:) після умови. Дужки навколо умови не є обов'язковими. Загальний вигляд: if умова_1: тіло блоку 1 elif умова_2: тіло блоку 2 (необов'язкова частина) else: тіло блоку інакше (необов'язкова частина) Приклад (повна конструкція):

x = 10
if x > 0:
    print("Додатне")
elif x == 0:
    print("Нуль")
else:
    print("Від'ємне")

Що таке булеві оператори? Булеві (логічні) оператори — це оператори, які використовуються для побудови складних логічних виразів, результатом обчислення яких є істина (True) або хибність (False). У Python використовуються саме такі ключові слова: • and (логічне І): повертає True, тільки якщо обидва операнди істинні. • or (логічне АБО): повертає True, якщо хоча б один з операндів істинний. • not (логічне НІ): інвертує значення (змінює True на False і навпаки).
Логічні оператори для списків та різниця між “==” та “is”. Логічні оператори для списків: До списків (list) часто застосовують оператори входження: • in: перевіряє, чи міститься елемент у списку (наприклад, if 5 in my_list:). • not in: перевіряє відсутність елемента. Також списки підтримують булеву оцінку: порожній список [] оцінюється як False, непорожній — як True. Різниця між == та is: • == (рівність значень): перевіряє, чи значення двох об'єктів однакові. o Приклад: [1, 2] == [1, 2] поверне True. • is (ідентичність об'єкта): перевіряє, чи посилаються обидві змінні на той самий об'єкт у пам'яті (чи мають вони однакову id). o Приклад: Якщо створити два окремих списки a = [1] і b = [1], то a is b поверне False, хоча їх значення рівні.
Що таке цикл? Що таке умова та тіло циклу? Цикл — це алгоритмічна конструкція, яка дозволяє багаторазово виконувати певний набір інструкцій. • Умова циклу: це логічний вираз, який перевіряється перед (або після) кожною ітерацією. Якщо умова істинна (True), цикл продовжується; якщо хибна (False) — цикл завершується. • Тіло циклу: це блок коду, який виконується на кожній ітерації циклу, доки умова залишається істинною.
Способи організації циклів та їх доцільність. У Python існують два основних типи циклів:
Цикл for (цикл обходу ітерованого об'єкта): o Як працює: Проходить по елементах послідовності (список, рядок, range). o Коли доцільно: Коли відома кількість ітерацій заздалегідь або потрібно обробити кожен елемент колекції. o Приклад: for i in range(10): ...
Цикл while (цикл з передумовою): o Як працює: Виконується доти, доки умова є істинною. o Коли доцільно: Коли точна кількість повторень невідома заздалегідь і залежить від зміни змінних усередині циклу (наприклад, пошук числа, введення даних користувачем). o Приклад: while x < 100: ...
Що таке оператори модифікації циклів? Це спеціальні інструкції, які дозволяють змінити стандартний потік виконання циклу: • break: негайно перериває виконання циклу повністю (вихід із циклу). Використовується, наприклад, для дострокового виходу при знаходженні потрібного значення. • continue: перериває поточну ітерацію і переходить до початку наступної (до перевірки умови). Використовується, щоб пропустити певні елементи. • else (у циклах): специфічний оператор Python. Блок else виконується один раз після завершення циклу, тільки якщо цикл не був перерваний оператором break.
