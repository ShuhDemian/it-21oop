4. Розв’язати заданий приклад.
Дано довжини  сторін деякого трикутника. Знайти всі медіани трикутника (Довжина медіани, проведеної до сторони , рівна ). Визначити найбільшу з них.
```
import math
def median(a, b, c):
    return 0.5 * math.sqrt(2*b*b + 2*c*c - a*a)
def max_median(a, b, c):
    m_a = median(a, b, c)
    m_b = median(b, a, c)
    m_c = median(c, a, b)
    return max(m_a, m_b, m_c), m_a, m_b, m_c
a = float(input("Введіть сторону a: "))
b = float(input("Введіть сторону b: "))
c = float(input("Введіть сторону c: "))
max_m, m_a, m_b, m_c = max_median(a, b, c)
print("Медіани:")
print("m_a =", m_a)
print("m_b =", m_b)
print("m_c =", m_c)
print("Найбільша медіана =", max_m)
```
