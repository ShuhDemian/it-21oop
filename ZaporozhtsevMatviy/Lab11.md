## Виконання

1. Дати загальний опис принципів проєктування.

Принципи проєктування програмного забезпечення — це набір фундаментальних рекомендацій та підходів, які допомагають розробникам створювати гнучкий, зрозумілий, надійний та легкий у підтримці код. На відміну від конкретних шаблонів проєктування (Design Patterns), принципи мають більш абстрактний характер і задають загальний вектор архітектури системи. Вони спрямовані на те, щоб зменшити зв'язність (coupling) між компонентами, підвищити їхню з'єднуваність та захистити код від руйнівного впливу майбутніх змін. Дотримання цих правил дозволяє уникати «спагеті-коду», спрощує написання модульних тестів та робить командну розробку набагато ефективнішою.

2. Дати детальний опис одного із принципів SOLID з наведення прикладу коду.

Одним із найважливіших принципів із набору SOLID є Принцип відчиненості/закритості (Open/Closed Principle, OCP), сформульований Бертраном Мейєром. Він говорить, що програмні сутності (класи, модулі, функції тощо) повинні бути відкритими для розширення, але закритими для модифікації. Це означає, що ми маємо мати змогу додавати нову функціональність до програми без зміни вже існуючого, протестованого й працюючого коду. Досягається це зазвичай за допомогою поліморфізму, абстрактних класів та інтерфейсів.
Приклад на Python
Уявіть, що ми пишемо систему знижок для інтернет-магазину. Якщо реалізувати це через перевірку умов всередині класу, то при кожній новій знижці доведеться правити існуючий код:

```
# Порушення OCP: при додаванні нового типу доведеться змінювати цей клас
class DiscountCalculator:
    def calculate(self, order_type: str, price: float) -> float:
        if order_type == "regular":
            return price * 0.95
        elif order_type == "vip":
            return price * 0.85
        return price
```

Відповідно до принципу OCP, краще винести логіку в окремі класи через загальний інтерфейс (абстрактний клас). Тоді для додавання нової знижки нам не потрібно чіпати старий код — достатньо лише створити новий клас: 

```
from abc import ABC, abstractmethod

# Абстрактний базовий клас (інтерфейс)
class Discount(ABC):
    @abstractmethod
    def apply(self, price: float) -> float:
        pass

# Конкретна реалізація для звичайних клієнтів
class RegularDiscount(Discount):
    def apply(self, price: float) -> float:
        return price * 0.95

# Конкретна реалізація для VIP-клієнтів
class VIPDiscount(Discount):
    def apply(self, price: float) -> float:
        return price * 0.85

# Нова знижка (наприклад, святкова), додана без зміни попереднього коду
class HolidayDiscount(Discount):
    def apply(self, price: float) -> float:
        return price * 0.75

# Клас обробки замовлень залишається незмінним при додаванні нових знижок
class OrderProcessor:
    def checkout(self, price: float, discount: Discount) -> float:
        return discount.apply(price)
```
