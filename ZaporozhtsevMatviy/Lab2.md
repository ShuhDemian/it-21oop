## Хід роботи
1. Вивчити основи синтаксису текстів програм в Python 3. 
Основи синтаксису тексту (рядків) в Python 3 включають використання одинарних ('') або подвійних ("") лапок, підтримку Unicode, екранування символів через \, а також зручне форматування (f-рядки: f"{var}") та багаторядкові блоки (три лапки """ """)
```
print("Hello, World!")

# > Hello, World!
```

2. Розглянути поняття змінних в Python 3 та засвоїти їх прості типи.  
Змінна в Python - це іменоване посилання на об'єкт (дані) у пам'яті комп'ютера, яке створюється при першому присвоєнні значення за допомогою оператора =. Python має динамічну типізацію, тому тип даних визначається автоматично під час виконання. Змінні не зберігають дані безпосередньо, а вказують на них, що дозволяє одному об'єкту мати кілька імен.
```
x = 5
y = "John"
print(x)
print(y)

# > 5
# > John
```

3. Розглянути поняття динамічної типізації. 
Динамічна типізація в Python означає, що типи даних змінних визначаються автоматично під час виконання програми, а не під час написання коду.
```
x = 4       # x is of type int
x = "Sally" # x is now of type str
print(x)

# > Salty
```
