## Виконання

1. Ознайомитися із видами тестів та пірамідою тестування.

Піраміда тестування показує відношення між різними типами автоматизованих тестів, де основа визначає найширший шар, а верхівка — найвужчий.

У самій основі розташовані юніт-тести, які є найчисельнішими. Вони перевіряють ізольовані функції чи класи, працюють за мілісекунди, коштують найдешевше та дозволяють миттєво знаходити помилки в коді.

Посередині знаходяться інтеграційні тести. Вони перевіряють взаємодію між різними модулями системи, такими як база даних чи зовнішні API. Вони повільніші за юніт-тести, але допомагають виявити проблеми на стиках компонентів.

На самій верхівці розміщені сквозні або UI-тести. Вони симулюють реальну поведінку користувача через весь інтерфейс та стек технологій. Ці тести дають найбільшу впевненість у працездатності всієї системи, проте вони найповільніші у виконанні та найдорожчі в підтримці.

Головне правило цієї концепції полягає в тому, що низькорівневих тестів завжди має бути найбільше, оскільки вони забезпечують швидкий зворотний зв'язок і низьку вартість розробки, тоді як високорівневі тести виконуються довше і вимагають більше ресурсів.

2. Написати та виконати unit-тест на Python 3 використовуючи вбудований модуль unittest.

```
import unittest

def add(a, b):
    return a + b

class TestMathOperations(unittest.TestCase):
    
    def test_add_positive_numbers(self):
        result = add(2, 3)
        self.assertEqual(result, 5)

    def test_add_negative_numbers(self):
        result = add(-1, -1)
        self.assertEqual(result, -2)

if __name__ == '__main__':
    unittest.main()
```
