## Виконання

1. Дати теоретичний опис поведінкової групи шаблонів.

Поведінкові шаблони (Behavioral Patterns) — це категорія шаблонів проєктування, які зосереджені на алгоритмах та розподілі обов'язків між об'єктами. Вони описують не лише саму структуру класів чи об'єктів, а й те, як вони взаємодіють і комунікують між собою під час виконання програми.

Якщо твірні шаблони керують створенням об'єктів, а структурні — їхнім компонуванням, то поведінкові допомагають зробити складні алгоритми зв'язку гнучкими та керованими. Вони мінімізують жорстку зв'язність (tight coupling) між різними компонентами системи, дозволяючи об'єктам динамічно змінювати свою поведінку під час виконання програми без зміни коду самих класів. Це досягається завдяки винесенню алгоритмів або взаємодій в окремі класи-окуляри (або інтерфейси).

2. Індивідуальне завдання

Посередник (Mediator) — це поведінковий шаблон проєктування, який дозволяє зменшити зв'язність між безліччю класів, змушуючи їх спілкуватися не напряму, а через одного центрального посередника.

Шаблон пропонує винести всю комунікацію між об'єктами в окремий клас-посередник. Тепер об'єкти більше не знають один про одного — вони знають лише посередника і надсилають повідомлення йому. А посередник уже вирішує, кому саме це повідомлення передати. Це спрощує підтримку коду, бо замість складної мережі зв'язків кожен компонент спілкується лише з однією сутністю.

Коли використовувати:

- Когда система складається з багатьох класів, чиї зв'язки занадто заплутані й утворюють складну «павутину» (спагеті-код комунікацій).
- Коли важко повторно використати клас, оскільки він занадто сильно залежить від інших класів.
- Коли потрібно змінити поведінку взаємодії кількох класів, просто замінивши клас посередника.

Приклад коду на Python


```
from abc import ABC, abstractmethod

# 1. Інтерфейс Посередника
class ChatMediator(ABC):
    @abstractmethod
    def send_message(self, message: str, sender: 'User') -> None:
        pass

# 2. Конкретний Посередник (Груповий чат)
class ChatRoom(ChatMediator):
    def __init__(self):
        self.users = []

    def add_user(self, user: 'User') -> None:
        self.users.append(user)

    def send_message(self, message: str, sender: 'User') -> None:
        # Посередник розсилає повідомлення всім, окрім відправника
        for user in self.users:
            if user != sender:
                user.receive(message)

# 3. Базовий клас Учасника (Колега)
class User(ABC):
    def __init__(self, name: str, mediator: ChatMediator):
        self.name = name
        self.mediator = mediator

    @abstractmethod
    def send(self, message: str) -> None:
        pass

    @abstractmethod
    def receive(self, message: str) -> None:
        pass

# 4. Конкретний Учасник чату
class ChatUser(User):
    def send(self, message: str) -> None:
        print(f"[{self.name}] надсилає: '{message}'")
        # Користувач не знає інших, він спілкується через посередника
        self.mediator.send_message(message, self)

    def receive(self, message: str) -> None:
        print(f"[{self.name}] отримав повідомлення -> {message}")

# --- Приклад використання ---
if __name__ == "__main__":
    # Створюємо посередника (чат-кімнату)
    chat = ChatRoom()

    # Створюємо користувачів і реєструємо їх у посередника
    alice = ChatUser("Аліса", chat)
    bob = ChatUser("Борис", chat)
    charlie = ChatUser("Олег", chat)

    chat.add_user(alice)
    chat.add_user(bob)
    chat.add_user(charlie)

    # Аліса пише повідомлення — посередник доставляє його іншим
    alice.send("Привіт усім у чаті!")
```
