## Виконання

1. Дати теоретичний опис твірної групи шаблонів. 

Твірні шаблони (Creational Patterns) — це категорія шаблонів проєктування, які зосереджені на механізмах створення об'єктів. Їхня головна мета — зробити систему незалежною від того, як саме створюються, композируються та представляються її об'єкти.

У класичному програмуванні створення об'єктів через прямий виклик конструкторів (new або прямий виклик класу) часто призводить до жорсткої зв'язності (tight coupling) та ускладнює модифікацію коду, оскільки система починає залежати від конкретних класів. Твірні шаблони вирішують цю проблему, приховуючи логіку створення екземплярів. Замість того щоб розірвати код прямими викликами, програма оперує абстрактними інтерфейсами, а спеціальні твірні механізми беруть на себе створення конкретних об'єктів. Це дозволяє гнучко керувати створенням об'єктів залежно від контексту, економити ресурси або спрощувати додавання нових типів сутностей.

2. Індивідуальне завдання

Фабричний метод (Factory Method) — це твірний шаблон проєктування, який визначає загальний інтерфейс для створення об'єктів у суперкласі, але дозволяє підкласам змінювати тип об'єктів, що створюються.

Простими словами, замість того щоб безпосередньо створювати об'єкти за допомогою ключового слова чи прямого виклику конструктора (ClassName()), клас делегує цю задачу спеціальному методу (фабричному методу). Підкласи можуть перевизначити цей метод, щоб налаштувати або змінити процес створення конкретних екземплярів.

Коли використовувати:
- Коли заздалегідь невідомо, об'єкти яких саме типів і залежностей доведеться створювати.
- Коли потрібно надати користувачам бібліотеки чи фреймворку можливість розширювати її внутрішні компоненти.
- Коли потрібно економити системні ресурси шляхом повторного використання вже створених об'єктів (через кешування).

Приклад коду на Python

Уявіть, що у нас є фабрика, яка створює іграшки тварин. Нам не потрібно знати деталі створення кожної конкретної тварини — ми просто кажемо фабриці, яку тварину хочемо отримати.


```
from abc import ABC, abstractmethod

# 1. Абстрактний продукт (Плюшева іграшка з динаміком)
class PlushToy(ABC):
    @abstractmethod
    def play_sound(self) -> str:
        pass

# 2. Конкретні продукти (різні іграшки)
class PlushBear(PlushToy):
    def play_sound(self) -> str:
        return "Динамік ведмедика: 'Привіт! Я міцний і пухнастий.'"

class PlushBunny(PlushToy):
    def play_sound(self) -> str:
        return "Динамік зайчика: 'Привіт! У мене довгі вушка.'"

# 3. Абстрактний творець (Фабрика іграшок)
class ToyFactory(ABC):
    @abstractmethod
    def create_toy(self) -> PlushToy:
        """Фабричний метод, який визначають підкласи"""
        pass

    def package_and_sell(self) -> str:
        """Основний процес, що використовує створений продукт"""
        toy = self.create_toy()
        return f"Іграшку упаковано. Тестуємо динамік -> {toy.play_sound()}"

# 4. Конкретні творці (Фабрика ведмедиків і фабрика зайчиків)
class BearFactory(ToyFactory):
    def create_toy(self) -> PlushToy:
        return PlushBear()

class BunnyFactory(ToyFactory):
    def create_toy(self) -> PlushToy:
        return PlushBunny()

# --- Приклад використання ---
if __name__ == "__main__":
    print("--- Виробництво ведмедиків ---")
    bear_factory = BearFactory()
    print(bear_factory.package_and_sell())

    print("\n--- Виробництво зайчиків ---")
    bunny_factory = BunnyFactory()
    print(bunny_factory.package_and_sell())
```
