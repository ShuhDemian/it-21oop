# Варіант 3

Задано масив цілих чисел розмірності n. Вивести лише ті елементи, для яких виконується умова a(i) <= i.

```
n = int(input("Введіть розмірність масиву n: "))
a = []

print(f"Введіть {n} цілих чисел:")
for _ in range(n):
    a.append(int(input()))

print("\nЕлементи, що задовольняють умову a[i] <= i:")
print(f"{'Індекс (i)':<12} | {'Значення (a[i])':<15}")
print("-" * 30)

for i in range(len(a)):
    if a[i] <= i:
        print(f"{i:<12} | {a[i]:<15}")
```
