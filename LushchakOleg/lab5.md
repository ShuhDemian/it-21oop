3. Ознайомитися з поняттям змінної (властивості) обʼєкту. Навчитися їх

```
class Car:
    def __init__(brand, year):
        self.brand = brand 
        self.year = year     

car1 = Car("BMW", 2015)

print("Марка авто:", car1.brand)
print("Рік випуску:", car1.year)

car1.brand = "Audi"
car1.year = 2020

print("\nПісля зміни:")
print("Марка авто:", car1.brand)
print("Рік випуску:", car1.year)
```
4. Ознайомитися з поняттям функцій об’єкту. Навчитися їх оголошувати
та викликати.
```
class Calculator:
    def add(self, a, b):
        return a + b
    def subtract(self, a, b):
        return a - b

    def multiply(self, a, b):
        return a * b

    def divide(self, a, b):
        if b != 0:
            return a / b
        else:
            return "Ділення на нуль неможливе"


calc = Calculator()

print("Додавання:", calc.add(10, 5))
print("Віднімання:", calc.subtract(10, 5))
print("Множення:", calc.multiply(10, 5))
print("Ділення:", calc.divide(10, 5))
```
