## Запитання для самоконтролю
1. Як встановити Python і запустити програму?
Необхідно завантажити Python з офіційного сайту, виконати встановлення (додавши Python до змінної PATH), після чого створити файл з розширенням .py та запустити його через термінал або IDE.

2. Основні відмінності Windows і Unix-подібних систем:
Відмінності полягають у командах терміналу, форматі шляхів до файлів, чутливості до регістру та загальній структурі системи. У Unix-подібних ОС термінал використовується частіше.

3. Структура найпростішої програми на Python:
Програма складається з послідовних інструкцій, які виконуються зверху вниз. Може містити коментарі та прості команди, наприклад, для виведення тексту.
