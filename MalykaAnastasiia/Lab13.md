  ## Хід роботи
  
  1. Дати теоретичний опис поведінкової групи шаблонів. 
  
Поведінкові шаблони описують, як об'єкти взаємодіють між собою та розподіляють відповідальність за виконання дій. Вони зосереджені не на структурі класів, а на алгоритмах і потоках керування між об'єктами — хто кому і коли передає команди чи сповіщення.

До групи належать: Strategy (набір взаємозамінних алгоритмів), Observer (сповіщення залежних об'єктів про зміни), State (зміна поведінки залежно від внутрішнього стану), Command (перетворення запиту на окремий об'єкт), Template Method (скелет алгоритму з кроками, що перевизначаються), Iterator (послідовний обхід колекції)

  2. Відповідно до индивідуального завдання: 

     - дати теоретичний опис даного шаблону;

Command перетворює запит (дію) на окремий об'єкт. Замість того, щоб клієнт напряму викликав метод об'єкта-виконавця, він створює об'єкт-команду, яка зберігає посилання на виконавця і знає, який саме метод викликати.

Це дозволяє передавати команди як параметри, ставити їх у чергу, логувати, скасовувати (undo) — тобто працювати із самою дією як зі звичайним об'єктом.

Учасники: Command — інтерфейс з методом execute(); ConcreteCommand — зберігає посилання на об'єкт-виконавець (Receiver) і викликає його метод; Receiver — клас, що реально виконує дію; Invoker — викликає execute() команди, не знаючи деталей дії; Client — створює команду і призначає їй Receiver.

  - навести приклад коду який реалізовує даний шаблон

class Light:
    def on(self):
        print("Light is ON")


class LightOnCommand:
    def __init__(self, light):
        self.light = light

    def execute(self):
        self.light.on()


light = Light()
command = LightOnCommand(light)
command.execute()
