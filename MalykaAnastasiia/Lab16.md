 1. Ознайомитися із видами тестів та пірамідою тестування.

Тестування — це перевірка того, що програма працює правильно і робить саме те, що від неї очікують. Чим раніше знайдена помилка, тим дешевше її виправити.

Види тестів

Unit-тести (модульні) перевіряють найменші частини коду окремо, наприклад одну функцію чи один метод. Вони швидкі та прості.

Інтеграційні тести перевіряють, як кілька частин програми працюють разом, наприклад чи правильно програма записує дані в базу даних.

Системні тести перевіряють програму як єдине ціле, ніби її перевіряє користувач.

E2E-тести (end-to-end, наскрізні) імітують реальні дії користувача від початку до кінця, наприклад відкрити сайт, увійти в акаунт, зробити замовлення.

Також розрізняють приймальні тести (чи задовольняє програма вимоги замовника), регресійні (чи не зламалося старе після нових змін) і навантажувальні (чи витримує програма велику кількість користувачів).

В основі піраміди лежать unit-тести: їх має бути найбільше, бо вони швидкі, прості й дешеві. Вище йдуть інтеграційні, яких потрібно менше. На вершині E2E-тести: вони повільні та дорогі, тому їх мало. Така структура дозволяє швидко знаходити більшість помилок, не витрачаючи багато часу й ресурсів.


  2. Написати та виконати unit-тест на Python 3 використовуючи вбудований модуль unittest. 

unittest вже вбудований у Python, його не потрібно встановлювати. Тест це клас, який успадковується від unittest.TestCase, а кожна перевірка це метод, назва якого починається з test_.

`import unittest`

`def add(a, b):`

`    return a + b`

`def divide(a, b):`

`    if b == 0:`

`        raise ValueError("Ділення на нуль")`

`    return a / b`

`class TestCalculator(unittest.TestCase):`

`    def test_add(self):`

`        self.assertEqual(add(2, 3), 5)`

`    def test_add_negative(self):`

`        self.assertEqual(add(-1, 1), 0)`

`    def test_divide(self):`

`        self.assertEqual(divide(10, 2), 5)`

`    def test_divide_by_zero(self):`

`        with self.assertRaises(ValueError):`

`            divide(10, 0)`

`if __name__ == "__main__":`

`    unittest.main()`
