  Мета: познайомитися з групою твірних шаблонів проєктування.

  ## Хід роботи
  
  1.Дати теоретичний опис твірної групи шаблонів.
  
Твірні шаблони відповідають за створення об'єктів. Їхня мета — відокремити код створення об'єкта від коду, що його використовує. Завдяки цьому легше змінювати спосіб створення об'єктів, не переписуючи весь код.
До групи належать: Singleton (один екземпляр класу), Factory Method (створення через метод), Abstract Factory (створення сімейств об'єктів), Builder (покрокове створення складного об'єкта), Prototype (створення через копіювання).

  2. Відповідно до индивідуального завдання:

     - дати теоретичний опис даного шаблону;
    
Prototype дозволяє створювати нові об'єкти не через new і конструктор, а шляхом копіювання (клонування) вже готового об'єкта. Для цього клас реалізує метод clone(), який повертає копію самого себе.

Це зручно, коли створення об'єкта з нуля складне або дороге, а простіше взяти готовий екземпляр і скопіювати його.

Учасники: Prototype — базовий клас з методом clone(); ConcretePrototype — клас, що реалізує клонування; Client — використовує clone(), не знаючи конкретного типу об'єкта.

     - навести приклад коду який реалізовує даний шаблон

`import copy`

`class Shape:`

`    def clone(self):`

`        return copy.deepcopy(self)`

`class Circle(Shape):`

`    def __init__(self, radius):`

`        self.radius = radius`

`    def print(self):`

`        print(f"Circle with radius {self.radius}")`

`original = Circle(5)`

`copy_of_original = original.clone()`

`original.print()`

`copy_of_original.print()`
