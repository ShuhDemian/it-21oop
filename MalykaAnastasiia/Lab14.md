1. Дати загальний опис принципів проєктування.

Принципи проєктування — це загальні правила, які допомагають писати код так, щоб його було легко читати, змінювати та розширювати. На відміну від шаблонів проєктування, які дають готове рішення конкретної задачі, принципи є радше орієнтирами: вони підказують, як розділяти код на класи й модулі та як зробити їх незалежними один від одного.

Найвідоміші принципи: SOLID (п'ять правил для об'єктно-орієнтованого проєктування), DRY (Don't Repeat Yourself — не повторюй код, а виноси спільне в одне місце), KISS (Keep It Simple — роби рішення якомога простішим) і YAGNI (You Aren't Gonna Need It — не пиши того, що поки не потрібно).

SOLID складається з п'яти принципів:

S — Single Responsibility (принцип єдиної відповідальності): один клас — одна задача.

O — Open/Closed (відкритості/закритості): клас відкритий для розширення, але закритий для зміни.

L — Liskov Substitution (підстановки Барбари Лісков): нащадка можна використовувати замість батьківського класу без поломок.

I — Interface Segregation (розділення інтерфейсів): краще багато маленьких інтерфейсів, ніж один великий.

D — Dependency Inversion (інверсії залежностей): код має залежати від абстракцій, а не від конкретних класів.


2. Дати детальний опис одного із принципів SOLID з наведенням прикладу коду. (Single Responsibility)

У класу має бути лише одна причина для змін, тобто він відповідає за одну конкретну задачу. Якщо клас робить кілька різних речей (наприклад, і рахує дані, і зберігає їх у файл), то зміна в одній частині може зламати іншу, а сам клас стає важко читати й тестувати.

Код:

`class Report:`

`    def __init__(self, text):`

`        self.text = text`

`    def count_words(self):`

`        return len(self.text.split())`

`class ReportSaver:`

`    def save(self, report, filename):`

`        with open(filename, "w") as f:`

`            f.write(report.text)`

`report = Report("Hello design principles")`

`print(report.count_words())  # 3`

`saver = ReportSaver()`

`saver.save(report, "report.txt")`
