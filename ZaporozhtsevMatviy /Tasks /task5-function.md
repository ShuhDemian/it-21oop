# Варіант 3

Натуральне n-значне число називається числом Амстронга, якщо сума його цифр, 
піднесена до степеня n, дорівнює самому числу. Знайти всі такі числа від 1 до k.


```
def is_armstrong(k):
    for n in range(k):
        x = 0
        for i in str(n):
            x = x + int(i)**len(str(n))
        if x == n:
            print(n)

is_armstrong(10000)
```
