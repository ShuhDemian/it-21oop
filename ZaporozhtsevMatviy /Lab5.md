## Львів 2026

Мета роботи – ознайомитися з поняттями класів та об’єктів та закріпити 
на практиці методи їх створення та використання.

## Хід роботи

1. Навчитися оголошувати класи в Python 3.

```
class Class0:
    def __init__(self):
        return
```

2. Навчитися створювати об’єкти (“class instances”). 

```
class Class0:
    def __init__(self):
        return

obj = Class0()
```

3. Ознайомитися з поняттям змінної (властивості) обʼєкту. Навчитися їх 
задавати та отримувати їхні значення.

```
class Class0:
    def __init__(self, arg1, arg2):
        self.arg1 = arg1
        self.arg2 = arg2

obj = Class0(1, "Dva")
print(obj.arg1, obj.arg2)
obj.arg1 = "Odyn"
```

5. Ознайомитися з поняттям функцій об’єкту. Навчитися їх оголошувати 
та викликати.
```
class Class0:
    def __init__(self, arg1, arg2):
        self.arg1 = arg1
        self.arg2 = arg2
    
    def say(self, a):
        print(self.arg1, self.arg2, a)


obj = Class0(1, "Dva")
obj.say(5)
```
