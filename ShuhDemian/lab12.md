# 1.Дати теоретичний опис твірної групи шаблонів.
Твірні шаблони проєктування

Твірні шаблони — це група шаблонів проєктування, яка відповідає за створення об'єктів.

Їх основне призначення — відокремити процес створення об'єкта від його використання. Це дозволяє зробити програму більш гнучкою та спрощує подальше розширення програмного забезпечення.

До найбільш відомих твірних шаблонів належать:

Factory Method — Фабричний метод;
Abstract Factory — Абстрактна фабрика;
Builder — Будівельник;
Prototype — Прототип;
Singleton — Одинак.
# 2.Відповідно до индивідуального завдання:
Теоретичний опис

Factory Method (Фабричний метод) — це твірний шаблон проєктування, який визначає метод для створення об’єкта, але дозволяє дочірнім класам визначати, який саме об’єкт буде створено.

У даному прикладі шаблон використовується для створення різних видів транспорту.

# Код програми
```
from abc import ABC, abstractmethod


class Transport(ABC):
    @abstractmethod
    def deliver(self):
        pass


class Car(Transport):
    def deliver(self):
        return "Доставка автомобілем"


class Truck(Transport):
    def deliver(self):
        return "Доставка вантажівкою"


class Logistics(ABC):
    @abstractmethod
    def create_transport(self):
        pass

    def plan_delivery(self):
        transport = self.create_transport()
        print(transport.deliver())


class CarLogistics(Logistics):
    def create_transport(self):
        return Car()


class TruckLogistics(Logistics):
    def create_transport(self):
        return Truck()


car_logistics = CarLogistics()
car_logistics.plan_delivery()

truck_logistics = TruckLogistics()
truck_logistics.plan_delivery()
```
Результат виконання
Доставка автомобілем
Доставка вантажівкою
UML-діаграма
```
            
          ┌─────────────────┐
          │   Transport     │
          ├─────────────────┤
          │ + deliver()     │
          └────────┬────────┘
                   △
          ┌────────┴────────┐
          │                 │
     ┌───────────┐    ┌───────────┐
     │    Car    │    │   Truck   │
     ├───────────┤    ├───────────┤
     │+deliver() │    │+deliver() │
     └───────────┘    └───────────┘
```
```
            
          ┌─────────────────────┐
          │      Logistics      │
          ├─────────────────────┤
          │ + create_transport()│
          │ + plan_delivery()  │
          └──────────┬──────────┘
                     △
              ┌──────┴──────┐
              │             │
     ┌────────────────┐ ┌────────────────┐
     │ CarLogistics   │ │ TruckLogistics │
     ├────────────────┤ ├────────────────┤
     │+create_transport│ │+create_transport│
     └───────┬────────┘ └───────┬────────┘
             │                  │
             ▼                  ▼
            Car               Truck
```
У цьому прикладі Transport є базовим продуктом, Car і Truck — конкретними продуктами. Клас Logistics містить фабричний метод create_transport(), а дочірні класи визначають, який конкретний транспорт буде створено.
