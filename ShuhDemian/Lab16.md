## Завдання 1. Ознайомитися із видами тестів та пірамідою тестування

### Види тестування програмного коду

**1. Модульне тестування (Unit Testing)**

Перевіряє окремі частини програми, наприклад функції, методи або класи. Допомагає швидко виявляти помилки в конкретних компонентах.

**2. Інтеграційне тестування (Integration Testing)**

Перевіряє взаємодію між окремими компонентами програми, наприклад між програмним модулем і базою даних.

**3. Системне тестування (System Testing)**

Перевіряє роботу всієї програми як єдиного цілого та відповідність її встановленим вимогам.

**4. Приймальне тестування (Acceptance Testing)**

Перевіряє, чи відповідає програма потребам користувача та чи готова вона до використання.

**5. Регресійне тестування (Regression Testing)**

Повторно перевіряє програму після внесення змін, щоб переконатися, що раніше реалізовані функції продовжують працювати правильно.

### Піраміда тестування

Піраміда тестування — це модель, яка показує рекомендоване співвідношення різних видів автоматизованих тестів.

1. **Модульні тести** — нижній рівень піраміди. Їх найбільше, вони перевіряють окремі функції та виконуються швидко.
2. **Інтеграційні тести** — середній рівень. Перевіряють взаємодію між компонентами програми.
3. **Системні та наскрізні тести** — верхній рівень. Перевіряють роботу програми або основних сценаріїв користувача. Їх зазвичай менше, оскільки вони складніші й повільніші.

Отже, піраміда передбачає велику кількість модульних тестів, меншу кількість інтеграційних і ще меншу кількість наскрізних тестів.

## Завдання 2. Написати та виконати unit-тест на Python 3, використовуючи вбудований модуль unittest

### 2.1. Створення файлу calculator.py

Створимо простий модуль із функціями додавання, віднімання, множення та ділення.

```python
def add(a, b):
    return a + b


def subtract(a, b):
    return a - b


def multiply(a, b):
    return a * b


def divide(a, b):
    if b == 0:
        raise ValueError("Ділення на нуль неможливе")
    return a / b
```

### 2.2. Створення файлу test_calculator.py

Для перевірки функцій використаємо вбудований модуль `unittest`.

```python
import unittest
from calculator import add, subtract, multiply, divide


class TestCalculator(unittest.TestCase):

    def test_add(self):
        self.assertEqual(add(2, 3), 5)

    def test_subtract(self):
        self.assertEqual(subtract(5, 3), 2)

    def test_multiply(self):
        self.assertEqual(multiply(4, 3), 12)

    def test_divide(self):
        self.assertEqual(divide(10, 2), 5)

    def test_divide_by_zero(self):
        with self.assertRaises(ValueError):
            divide(10, 0)


if __name__ == "__main__":
    unittest.main()
```

### 2.3. Пояснення коду

- `import unittest` — підключає модуль для створення та виконання тестів.
- `from calculator import ...` — імпортує функції, які потрібно перевірити.
- `class TestCalculator(unittest.TestCase)` — створює клас тестів.
- `test_add()` — перевіряє правильність додавання.
- `test_subtract()` — перевіряє правильність віднімання.
- `test_multiply()` — перевіряє правильність множення.
- `test_divide()` — перевіряє правильність ділення.
- `test_divide_by_zero()` — перевіряє, чи виникає помилка під час ділення на нуль.
- `assertEqual()` — порівнює фактичний результат з очікуваним.
- `assertRaises()` — перевіряє, чи виникає вказаний тип помилки.
- `unittest.main()` — запускає тести.

### 2.4. Виконання тестів

Потрібно зберегти обидва файли в одній папці:

- `calculator.py`
- `test_calculator.py`

Відкрити термінал у цій папці та виконати команду:

```bash
python -m unittest -v
```

Якщо команда `python` не працює, у Windows можна спробувати:

```bash
py -m unittest -v
```

### 2.5. Очікуваний результат

Якщо всі тести пройдуть успішно, у терміналі буде виведено приблизно такий результат:

```text
test_add ... ok
test_divide ... ok
test_divide_by_zero ... ok
test_multiply ... ok
test_subtract ... ok

----------------------------------------------------------------------
Ran 5 tests

OK
```

Це очікуваний результат за умови, що файли створено правильно та всі тести успішно виконуються.

### 2.6. Аналіз результатів

Було створено п'ять модульних тестів для перевірки функцій калькулятора.

| Тест | Перевірка | Очікуваний результат |
|---|---|---|
| `test_add` | Додавання 2 і 3 | 5 |
| `test_subtract` | Віднімання 3 від 5 | 2 |
| `test_multiply` | Множення 4 на 3 | 12 |
| `test_divide` | Ділення 10 на 2 | 5 |
| `test_divide_by_zero` | Ділення на нуль | `ValueError` |

У разі успішного виконання всіх тестів програма виведе повідомлення `OK`. Це означає, що всі перевірені функції відповідають очікуваним результатам.
