# **Відповіді на запитання самоконтролю**

**1\. Як встановити середовище розробки Python? Як запустити виконання програми?**

Для встановлення Python 3 необхідно завантажити інсталятор з офіційного сайту python.org та запустити його. Під час встановлення слід відмітити опцію "Add Python to PATH". Для запуску програми у Windows використовують команду python назва*файлу.py у командному рядку, а в Unix-подібних системах - python3 назва*файлу.py. Також програму можна запустити з середовища розробки (IDE), наприклад PyCharm або VS Code.

**2\. Які основні відмінності в роботі під ОС Windows та Unix-подібними системами?**

У Windows команда запуску Python - python, тоді як у Unix-подібних системах (Linux, macOS) використовується python3, щоб відрізнити від Python 2. Роздільник шляхів у Windows - зворотна коса риска (\\), а в Unix - пряма (/). Кінці рядків у файлах теж відрізняються: Windows використовує CRLF (\\r\\n), а Unix - LF (\\n). Крім того, у Unix-системах Python зазвичай вже встановлений за замовчуванням.

**3\. Поясніть структуру найпростішої програми на Python 3.**

Найпростіша програма на Python 3 складається з послідовних інструкцій, які виконуються зверху вниз. Наприклад:

name = input("Як вас звати?: ")

print(f"Привіт, {name}!")

Перший рядок - зчитування даних від користувача за допомогою функції input() і збереження результату у змінній name. Другий рядок - виведення тексту на екран за допомогою функції print(). Символ f перед рядком дозволяє підставляти значення змінних у текст за допомогою фігурних дужок {name}.
