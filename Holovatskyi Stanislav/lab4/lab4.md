# **Хід роботи**

- Освоїв синтаксис функцій у Python 3.

Функція - це іменований блок коду, який виконує певну задачу і може повертати результат. Оголошується за допомогою ключового слова def.

\# Базовий синтаксис функції

def greet(name):

return f'Привіт, {name}!'

\# Виклик функції

result = greet('Станіслав')

print(result) # Привіт, Станіслав!

\# Функція без повернення значення

def print_line(char='-', length=30):

print(char \* length)

print_line() # ------------------------------

print_line('=', 20) # ====================

- def - ключове слово для оголошення функції
- return - повертає значення з функції (якщо відсутнє - повертається None)
- Тіло функції - обов'язково з відступом

- Закріпив поняття параметрів та аргументів функції.

Параметри - це змінні, що вказуються при оголошенні функції. Аргументи - це конкретні значення, що передаються при виклику.

\# Позиційні аргументи

def add(a, b):

return a + b

print(add(3, 5)) # 8

\# Іменовані аргументи

def describe(name, age, city='Львів'):

return f'{name}, {age} р., {city}'

print(describe('Станіслав', 20)) # Станіслав, 20 р., Львів

print(describe(age=20, name='Станіслав')) # іменований виклик

\# \*args - довільна кількість позиційних аргументів

def total(\*args):

return sum(args)

print(total(1, 2, 3, 4, 5)) # 15

\# \*\*kwargs - довільна кількість іменованих аргументів

def show_info(\*\*kwargs):

for key, val in kwargs.items():

print(f'{key}: {val}')

show_info(name='Станіслав', group='Іт-21', city='Львів')

- Позиційні аргументи - передаються у порядку оголошення параметрів
- Іменовані аргументи - передаються з вказівкою імені параметра
- Аргументи за замовчуванням - мають значення, якщо аргумент не передано
- \*args - збирає довільну кількість позиційних аргументів у кортеж
- \*\*kwargs - збирає довільну кількість іменованих аргументів у словник

- Вивчив методи роботи з функціями: виклик функцій, передача їх як параметрів у інші функції ("callback").

У Python функції є об'єктами першого класу - їх можна зберігати у змінних, передавати як аргументи та повертати з інших функцій.

\# Функція як аргумент (callback)

def apply(func, value):

return func(value)

def square(x):

return x \*\* 2

def double(x):

return x \* 2

print(apply(square, 5)) # 25

print(apply(double, 5)) # 10

\# Передача функції у map()

numbers = \[1, 2, 3, 4, 5\]

squared = list(map(square, numbers))

print(squared) # \[1, 4, 9, 16, 25\]

\# Lambda - анонімна функція

cube = lambda x: x \*\* 3

print(cube(4)) # 64

evens = list(filter(lambda x: x % 2 == 0, numbers))

print(evens) # \[2, 4\]

\# Функція, що повертає функцію (замикання)

def multiplier(factor):

def multiply(x):

return x \* factor

return multiply

triple = multiplier(3)

print(triple(7)) # 21

- Callback - функція, що передається як аргумент і викликається всередині іншої функції
- map(func, iterable) - застосовує функцію до кожного елемента послідовності
- filter(func, iterable) - фільтрує елементи за умовою функції
- lambda - анонімна однорядкова функція
- Замикання (closure) - функція, що «пам'ятає» змінні з оточуючого контексту

def analyze(numbers):

if not numbers:

return None

return {

'min': min(numbers),

'max': max(numbers),

'sum': sum(numbers),

'avg': round(sum(numbers) / len(numbers), 2),

'count': len(numbers)

}

def get_numbers():

raw = input('Введіть числа через пробіл: ')

return list(map(float, raw.split()))

def print_stats(stats):

if stats is None:

print('Список порожній!')

return

labels = {'min': 'Мінімум', 'max': 'Максимум',

'sum': 'Сума', 'avg': 'Середнє', 'count': 'Кількість'}

for key, label in labels.items():

print(f'{label}: {stats\[key\]}')

# **Відповіді на запитання самоконтролю**

**1\. Назвіть переваги використання функцій.**

Функції дають низку переваг: повторне використання коду (один раз написав - викликаєш скільки завгодно), декомпозиція задачі на менші підзадачі, що покращує читабельність програми, легкість тестування та налагодження окремих частин, уникнення дублювання коду, а також можливість абстрагування - приховання деталей реалізації за зрозумілим іменем функції.

**2\. Як оголосити функцію в Python 3?**

Функція оголошується за допомогою ключового слова _def_, після якого вказується ім'я функції, дужки з параметрами та двокрапка. Тіло функції записується з відступом:

def назва_функції(параметр1, параметр2):

\# тіло функції

return результат

Якщо функція нічого не повертає, оператор return можна не вказувати - тоді вона повертає None.

**3\. Як викликати функцію?**

Функція викликається за її іменем з дужками, в яких передаються аргументи: назва*функції(аргумент1, аргумент2). Якщо функція не приймає параметрів, дужки все одно обов'язкові: назва*функції(). Результат виклику можна зберегти у змінну: result = назва*функції(аргументи), або використати безпосередньо: print(назва*функції(аргументи)).

**4\. Що таке аргументи функції? Що таке параметри функції?**

Параметри - це змінні-«заглушки», що оголошуються в дужках при визначенні функції (def f(a, b)). Вони діють лише всередині функції. Аргументи - це конкретні значення, що передаються при виклику функції (f(3, 5)). Тобто параметри - у визначенні, аргументи - у виклику.

**5\. Як задати аргументам функції за замовчуванням?**

Значення за замовчуванням задаються у визначенні функції через знак «=»:

def greet(name, greeting='Привіт'):

print(f'{greeting}, {name}!')

greet('Станіслав') # Привіт, Станіслав!

greet('Станіслав', 'Добрий день') # Добрий день, Станіслав!

Параметри зі значеннями за замовчуванням мають стояти після обов'язкових параметрів.

**6\. Що таке функції першого класу?**

Функції першого класу (first-class functions) - це концепція, при якій функції є повноцінними об'єктами мови: їх можна присвоювати змінним, зберігати у структурах даних (списках, словниках), передавати як аргументи іншим функціям і повертати як результат функцій. Python повністю підтримує цю концепцію, що робить мову дуже гнучкою.

**7\. Що таке функції вищого порядку?**

Функції вищого порядку - це функції, які приймають інші функції як аргументи або повертають функції як результат. Класичні приклади в Python: map() - застосовує функцію до кожного елемента послідовності; filter() - відбирає елементи за умовою-функцією; sorted() з параметром key - сортує за функцією. Власний приклад: функція apply(func, value), яка приймає callback і викликає його на значенні.
