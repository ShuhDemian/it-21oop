**Відповіді на запитання самоконтролю**

**1. Що таке індентація? Для чого індентація використовується в Python
3?**

Індентація --- це відступи на початку рядків коду. На відміну від
більшості мов програмування, в Python 3 відступи є обов\'язковими і
замінюють фігурні дужки: саме вони визначають блоки коду (тіло функцій,
умов, циклів тощо). Стандартний відступ --- 4 пробіли. Порушення
індентації призводить до помилки IndentationError.

**2. Як задати змінну в Python 3? Як задати її тип? Чи можна змінити тип
змінної? Чи можна задати значення декільком змінним одночасно?**

Змінна задається простим присвоєнням: x = 5. Тип визначається
автоматично (динамічна типізація), але можна явно перетворити тип через
int(), str(), float() тощо. Оскільки Python динамічно типізований, тип
змінної може змінитися після нового присвоєння. Задати значення
декільком змінним одночасно можна так: a, b, c = 1, 2, 3 або a = b = c =
0.

**3. Що таке динамічна типізація? Які переваги та недоліки вона має?**

Динамічна типізація означає, що тип змінної визначається автоматично під
час виконання програми. Перевага --- простота і швидкість написання
коду, не потрібно явно вказувати типи. Недолік --- можливі помилки типів
під час виконання, які складніше виявити на ранніх етапах розробки.

**4. Які базові операції над числами підтримує Python 3? Як здійснити
приведення типів?**

Python підтримує: додавання (+), віднімання (-), множення (\*), ділення
(/), ціле ділення (//), остачу від ділення (%), піднесення до степеня
(\*\*). Приведення типів здійснюється через вбудовані функції: int(),
float(), str(), bool(). Наприклад, int(\'42\') перетворює рядок на ціле
число.

**5. Що таке список (List) у Python 3? Як звернутися до елемента
списку?**

Список --- це впорядкована змінювана колекція елементів будь-яких типів,
що оголошується у квадратних дужках: my_list = \[1, \'два\', 3.0\].
Доступ до елементів здійснюється за індексом (нумерація з 0):
my_list\[0\] поверне 1. Підтримується негативна індексація:
my_list\[-1\] повертає останній елемент.

**6. Які основні оператори є в Python 3?**

В Python 3 є арифметичні оператори (+, -, \*, /, //, %, \*\*), оператори
порівняння (==, !=, \>, \<, \>=, \<=), логічні оператори (and, or, not),
оператори присвоєння (=, +=, -=, \*=), а також оператор перевірки
належності (in, not in) та перевірки ідентичності (is, is not).

**7. Як форматувати рядки в Python 3?**

Найсучасніший спосіб --- f-рядки: f\'Привіт, {name}!\'. Також можна
використовувати метод .format(): \'Привіт, {}!\'.format(name), або
старий спосіб із % --- \'Привіт, %s!\' % name. F-рядки найбільш
читабельні та рекомендовані з Python 3.6+.

**8. Як рядки в Python 3 схожі на списки?**

Рядки в Python 3, як і списки, є послідовностями, тому підтримують
індексацію (s\[0\]), зрізи (s\[1:4\]), функцію len(), ітерацію у циклі
for. Але на відміну від списків, рядки є незмінними (immutable) ---
окремий символ рядка змінити не можна.

**9. Що таке словник (Dictionary) у Python 3? Як з ним працювати?**

Словник --- це колекція пар «ключ: значення», що оголошується у фігурних
дужках: d = {\'ім\\\'я\': \'Станіслав\'}. Доступ до значення ---
d\[\'ім\\\'я\'\]. Додавання/зміна --- d\[\'новий_ключ\'\] = значення.
Основні методи: .keys() --- всі ключі, .values() --- всі значення,
.items() --- всі пари. Ключі мають бути унікальними та незмінного типу.
