- Засвоїв суть структурного програмування.

Структурне програмування - це підхід, при якому програма будується з трьох базових конструкцій: послідовності, розгалуження та циклу. Кожен блок має один вхід і один вихід, що забезпечує читабельність і передбачуваність коду.

- Послідовність - інструкції виконуються одна за одною зверху вниз
- Розгалуження - виконання різних гілок коду залежно від умови (if/elif/else)
- Цикл - повторення блоку коду певну кількість разів або поки виконується умова

- Навчився використовувати умовні оператори.

- elif - перевіряє додаткову умову, якщо попередня False
- else - виконується, якщо жодна умова не спрацювала

- Опанував методи роботи з циклами. Навчився визначати доцільність застосування різних типів циклів залежно від поставленої задачі.

Цикл for - використовується, коли кількість ітерацій відома заздалегідь або є ітерований об'єкт:

\# for - перебір діапазону

for i in range(1, 6):

\# for - перебір списку

\# enumerate - з індексом

Цикл while - використовується, коли кількість ітерацій залежить від умови:

\# while - виконується поки умова True

while n <= 5:

print(n)

n += 1

\# break та continue

for i in range(10):

if i == 3:

continue # пропустити 3

if i == 7:

break # зупинити цикл на 7

print(i)

- break - негайний вихід із циклу
- continue - перехід до наступної ітерації

# **Відповіді на запитання самоконтролю**

**1\. Дайте визначення поняттю "структурне програмування".**

Структурне програмування - це методологія розробки програм, заснована на використанні лише трьох базових управляючих конструкцій: послідовності (виконання команд одна за одною), розгалуження (вибір гілки виконання залежно від умови) та циклу (повторення блоку коду). Ця методологія підвищує читабельність, зрозумілість і надійність програм.

**2\. Який синтаксис умовних операторів у Python 3? Наведіть приклади відомих Вам умовних конструкцій.**

Умовний оператор if має такий синтаксис:

if умова:

\# блок 1

elif інша_умова:

\# блок 2

else:

\# блок 3

Також існує тернарний оператор: значення1 if умова else значення2. Наприклад: result = 'так' if x > 0 else 'ні'.

**3\. Що таке булеві оператори?**

Булеві (логічні) оператори - це оператори, що працюють зі значеннями True та False. У Python 3 є три основних: and (логічне «і» - повертає True якщо обидва операнди True), or (логічне «або» - повертає True якщо хоча б один True), not (логічне заперечення - інвертує значення). Результат булевих операцій використовується в умовних конструкціях та циклах.

**4\. Які логічні оператори можуть застосовуватися до змінних типу список (list)? У чому різниця між операторами "==" та "is"?**

До списків можна застосовувати оператор in (перевірка входження елемента), not in, а також == та is. Різниця між == та is: оператор == порівнює значення (вміст) двох об'єктів - True, якщо вміст однаковий. Оператор is порівнює ідентичність об'єктів - True лише якщо обидві змінні вказують на той самий об'єкт у пам'яті. Наприклад: a = \[1,2\]; b = \[1,2\]; a == b дасть True, але a is b дасть False, бо це різні об'єкти.
