# **Відповіді на запитання самоконтролю**

**1. Як створити порожній клас?**

Порожній клас створюється за допомогою ключового слова *class* та заглушки *pass* у тілі:

class MyClass:

`    `pass

Такий клас вже є повноцінним об'єктом Python і може використовуватися для створення екземплярів: obj = MyClass(). До нього можна динамічно додавати атрибути.

**2. Який метод призначений для створення нового об'єкта?**

Для ініціалізації нового об'єкта призначений метод \_\_init\_\_(self, ...). Він автоматично викликається Python одразу після виділення пам'яті для об'єкта. У ньому задаються атрибути екземпляра через self. Насправді виділення пам'яті виконує метод \_\_new\_\_(), але на практиці \_\_init\_\_() є тим методом, який програміст визначає для налаштування нового об'єкта.

**3. Що таке змінна класу? Чим вона відрізняється від змінної об'єкта?**

Змінна класу — це атрибут, оголошений у тілі класу поза будь-яким методом. Вона є спільною для всіх екземплярів і зберігається в самому класі. Змінна об'єкта (екземпляра) — оголошується всередині \_\_init\_\_ через self і є унікальною для кожного екземпляра. Якщо змінити змінну класу через ім'я класу — зміна торкнеться всіх екземплярів. Якщо присвоїти значення через екземпляр — створюється нова змінна екземпляра, що «перекриває» змінну класу лише для цього об'єкта.

**4. Що таке метод класу (@classmethod)? Чим він відрізняється від звичайного методу?**

Метод класу оголошується з декоратором @classmethod і отримує першим параметром cls — посилання на сам клас, а не на екземпляр. Він може викликатися як через клас (Employee.get\_count()), так і через екземпляр. Звичайний метод отримує self — посилання на конкретний екземпляр і має доступ до атрибутів об'єкта. Методи класу використовуються для роботи зі змінними класу та фабричних методів.

**5. Що робить метод \_\_del\_\_? Коли він викликається?**

Метод \_\_del\_\_ — це деструктор класу. Він автоматично викликається Python перед знищенням об'єкта: при явному виклику del obj, при виході об'єкта за межі scope або при завершенні програми. Використовується для «прибирання»: звільнення ресурсів, закриття файлів, оновлення лічильників. У нашому прикладі \_\_del\_\_ зменшує лічильник \_count при знищенні кожного працівника.
