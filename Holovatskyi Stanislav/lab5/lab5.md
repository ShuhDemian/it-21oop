1. Навчився створювати об'єкти ("class instances").

Об'єкт (екземпляр класу) створюється викликом класу як функції з потрібними аргументами.

\# Створення екземплярів

- Екземпляр — конкретний об'єкт, створений на основі класу
- isinstance(obj, Class) — перевіряє, чи є obj екземпляром Class

1. Ознайомився з поняттям змінної (властивості) об'єкта. Навчився їх задавати та отримувати.

Властивості об'єкта — це його атрибути, що зберігають стан. Доступ до них — через крапку. Можна задавати, читати та видаляти їх.

# **Відповіді на запитання самоконтролю**

**1. Дайте визначення поняттю "клас". Як оголосити найпростіший клас у Python 3?**

Клас — це шаблон (blueprint) для створення об'єктів, що визначає їхні атрибути (дані) і методи (поведінку). Клас є абстракцією реального об'єкта. Найпростіший клас оголошується так:

class MyClass:

`    `pass

Ключове слово *class* — оголошення класу; *pass* — заглушка для порожнього тіла.

**2. Що таке об'єкт? Як створюється об'єкт?**

Об'єкт (екземпляр класу) — це конкретна сутність, створена на основі класу. Якщо клас — це «форма для печива», то об'єкт — це конкретне «печиво». Об'єкт створюється викликом класу: obj = MyClass(). При цьому автоматично викликається метод \_\_init\_\_, якому передаються аргументи конструктора. Кожен об'єкт незалежний — зміна атрибутів одного не впливає на інший.

**3. У чому полягає різниця між класом і об'єктом?**

Клас — це опис (шаблон, тип), що існує в єдиному екземплярі і визначає структуру та поведінку. Об'єкт — це конкретна реалізація класу з власними значеннями атрибутів. Наприклад, клас Student описує студента взагалі, а student1 = Student('Станіслав', 'Іт-21') — конкретний студент. Від одного класу можна створити скільки завгодно об'єктів.

**4. Що таке змінна об'єкта?**

Змінна (атрибут, властивість) об'єкта — це іменоване поле, що зберігає певне значення, яке характеризує стан конкретного об'єкта. Атрибути екземпляра задаються всередині \_\_init\_\_ через self.назва = значення і є унікальними для кожного об'єкта. Доступ до них — через крапку: obj.атрибут. Слід відрізняти атрибути екземпляра (унікальні) від атрибутів класу (спільні для всіх об'єктів).
